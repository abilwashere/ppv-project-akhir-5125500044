# Roadmap Project Akhir — RuangPENS

Roadmap ini menjelaskan rencana pengembangan RuangPENS dari Sprint P10 hingga P14.

## P10 — Debugging dan Git
- Memeriksa kembali bug dan memperbaiki kesalahan pada aplikasi.
- Merapikan riwayat perubahan menggunakan Git.
- Memastikan fungsi pencarian ruangan, validasi input, dan petunjuk arah berjalan dengan baik.

## P11 — JavaScript ES Modules
- Memisahkan kode JavaScript menjadi modul sesuai tanggung jawabnya.
- Menggunakan `export` dan `import` untuk menghubungkan modul.
- Menguji kembali fungsi aplikasi setelah pemisahan kode.

## P12 — Komponen, Penyimpanan Aman, dan Maintenance
- Mengembangkan komponen antarmuka agar kode lebih terstruktur dan dapat digunakan kembali.
- Menerapkan penyimpanan data di browser sesuai kebutuhan aplikasi.
- Memastikan data yang disimpan ditangani dengan aman.
- Melakukan pemeliharaan dan pengujian ulang aplikasi.

## P13 — Konsep Produk
- Menyusun konsep produk berdasarkan kebutuhan pengguna.
- Menentukan target pengguna, permasalahan, dan fitur utama.
- Mengevaluasi kesesuaian fitur RuangPENS dengan kebutuhan pengguna.

## P14 — Demo Project Akhir
- Melakukan pengujian akhir pada fitur utama.
- Menyiapkan skenario demonstrasi aplikasi.
- Mendokumentasikan hasil pengembangan dan menampilkan demo RuangPENS.
